About Me

Director / Principal Engineer focused on applied and agentic AI, backed by 18+ years building distributed systems across embedded, cloud, and backend platforms. At Charter's Emerging Technology group, I build AI-native engineering workflows and agent platforms on AWS: sandboxed evaluation of AI coding agents, self-improving code-review agents, multi-agent document pipelines, and Model Context Protocol (MCP) integrations that connect agents to enterprise tools.

I bring production rigor to AI adoption through measurable evaluation, guardrails, least-privilege access, and reproducible infrastructure as code, alongside 0-to-1 proofs of concept in latency measurement and network-as-a-service APIs. Previously a Staff Software Engineer at EchoStar/Dish, I delivered large-scale backend services, telemetry pipelines, and patented product features for millions of users.

Agentic AI

Hands-on work building, evaluating, and putting AI agents to work across the software development lifecycle.

AI Coding-Agent Evaluation Platform

Designed and built an isolated sandbox for evaluating AI coding agents on AWS. It covers infrastructure as code in AWS CDK, repeatable multi-instance deployments, a reproducible Nix toolchain, and controlled network egress, so agents reach only what they're allowed to.

Self-Tuning Code-Review Agent

Built an automated loop that rewrites an AI code reviewer's instructions, scores each revision against a graded test suite across multiple models, and keeps a change only when it's statistically better, or shorter with no loss in quality.

Multi-Agent Document Intelligence

Orchestrated a multi-agent workflow that inventories large enterprise document sets, converts mixed formats, and extracts structured facts tagged by source for human review.

Agents Connected to Enterprise Tools

Connected AI agents to a corporate wiki and issue tracker through approved Model Context Protocol (MCP) servers, scoped and rate-limited to fit company access policy.
