# Shashikiran Javvaji — Personal Site

A plain HTML + CSS profile site. No build step, no frameworks.

© 2026 Shashikiran Javvaji. All rights reserved. Shared publicly for reference only; no license is granted to reuse it.

## Files

- `index.html` — all the content (edit text here)
- `styles.css` — colors, fonts, layout (colors are at the top)
- `assets/` — photo and favicon
- `CNAME` — custom domain (www.shashikiranjavvaji.site); do not delete

## Preview locally

Open `index.html` in a browser, or run:

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

## Publishing

GitHub Pages serves this repo directly: Settings → Pages → Deploy from a branch → `main` / root.
